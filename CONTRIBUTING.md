# Contributing to `surveymetrics`

We welcome contributions from quantitative social science researchers, statisticians, and R developers!

## Workflow
1. Fork `https://github.com/jubarajbag26-max/surveymetrics` and create a feature branch (`git checkout -b feat/new-test`).
2. Add your R function in `R/` with complete Roxygen2 documentation headers.
3. Add unit tests in `tests/testthat/test-surveymetrics.R`.
4. Ensure `R CMD check` passes with **0 errors, 0 warnings, and 0 notes**.
5. Submit a Pull Request detailing the statistical method and use case for review by `@jubarajbag26-max`.
