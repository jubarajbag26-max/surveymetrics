# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Data Privacy & Vulnerability Reporting
`surveymetrics` processes human-subject survey exports (such as Google Forms CSVs). To prevent accidental leakage of Personally Identifiable Information (PII) or code-injection via malformed CSV inputs:
- Do not commit raw participant email addresses or un-anonymized survey CSVs to the repository.
- If you discover a security or data-sanitization vulnerability, please open a private security advisory on `https://github.com/jubarajbag26-max/surveymetrics/security` or contact `@jubarajbag26-max` directly before disclosing it publicly.
